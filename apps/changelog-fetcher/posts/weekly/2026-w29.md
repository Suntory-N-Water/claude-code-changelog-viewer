2026年7月13日~7月19日の変更で、個人的に気になったものをピックアップしました。

サブエージェントを並列で走らせたり `settings.json` で権限を絞ったりしているとき、任せきりで大丈夫かな、と一瞬止まる場面が私はよくあります。今回選んだ 2 件は、どちらもそのモヤモヤに直接効く変更でした。

## v2.1.210

### 非推奨のパーミッションルールである Write、NotebookEdit、Glob に対する起動時の警告を追加した。

> - Added a startup warning for `Write(path)`, `NotebookEdit(path)`, and `Glob(path)` permission rules — use `Edit(path)` or `Read(path)` instead

複数のプロジェクトの `settings.json` に `Write(.env)` の形で禁止したいパスを並べていたので、これから起動のたびに一気に指摘されそうです。方針は理解できるのですが、警告だけでなく置き換えを提案してくれる仕組みも一緒にほしかったですね。

### ワークツリー隔離モードのサブエージェントが、自身のワークツリーではなくメインリポジトリに対して git コマンドを実行できてしまう問題を修正した。

> - Fixed `isolation: 'worktree'` subagents being able to run git-mutating commands against the main repo checkout instead of their own isolated worktree

並列で走らせたサブエージェントが、隔離されたワークツリーではなく親のリポジトリで `git` を動かしてしまうことが実際にありました。どこまで書き換わったのか追い切れず作業を止めていたので、隔離が厳格化されて並列で回しやすくなりそうです。
