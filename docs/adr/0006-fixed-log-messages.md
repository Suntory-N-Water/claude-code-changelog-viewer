# メッセージカタログのログ文言を固定する

## Context

ログの message に対象名や件数を埋め込むと、同じ事象でも文言が揺れ、検索・集計のキーとして使いにくい。テンプレートを増やすと呼び出し側の都合でカタログのコード数が増え、文言を統制する目的も失われる。

## Decision

`packages/common/src/log-messages/catalog.ts` の message は固定文にする。対象名、件数、識別子などの可変値は `attrs` に出す。既存のログ ID は維持し、カタログのコード総数を増やさない。

`params` による位置引数のテンプレート展開は廃止する。削除予定の app に残る呼び出しは、破壊的変更を明示したうえで `arg0` / `arg1` 属性へ機械的に移行する。

## Consequences

- message の完全一致検索とログ集計が安定する。
- 可変値は構造化属性として検索・集計できる。
- カタログの文言を変更する場合は、固定文の変更としてレビューできる。
