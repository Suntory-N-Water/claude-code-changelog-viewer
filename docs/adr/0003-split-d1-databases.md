# D1 データベースを正データ用とドキュメント検索用の2個に分ける

`wrangler d1 export` はデータベース単位の操作で、virtual table(FTS5)が1つでもあるとデータベース全体の export が失敗する。テーブル単位で除外することもできない。
D1 には常時有効な復元機能(Time Travel)があるが、保持期間は30日で、それを超えるバックアップは R2 への export に依存する。
AI 推論結果は再生成に費用と時間がかかるため、30日を超えるバックアップが必要になる。
そこで、AI 推論結果などを持つ「正データ用」と、公式ドキュメント本文と FTS5 インデックスを持つ「ドキュメント検索用」の2個に分け、正データ用だけを R2 へ定期的に export する。

## Consequences

- ドキュメント検索用データベースは export できないままになる。ただし失っても公式ドキュメントの再取得で復旧できるため許容する。
- 今回の移行で R2 に新たに置くのはこの export だけ。既存の週次記事画像用バケットはこの決定の対象外で、従来どおり使う。
