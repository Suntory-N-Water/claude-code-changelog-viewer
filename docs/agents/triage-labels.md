# Triage Labels

skill 群は triage の5つの正規ロールを前提に記述されている。このファイルは、それらのロールとこのリポジトリの issue tracker で実際に使うラベル文字列との対応を定義する。

| mattpocock/skills 側のラベル | このリポジトリのラベル | 意味                                 |
| ---------------------------- | ---------------------- | ------------------------------------ |
| `needs-triage`               | `needs-triage`         | メンテナによる評価が必要             |
| `needs-info`                 | `needs-info`           | 報告者からの追加情報を待っている     |
| `ready-for-agent`            | `ready-for-agent`      | 仕様が確定し、AFK エージェントで着手可能 |
| `ready-for-human`            | `ready-for-human`      | 人間による実装が必要                 |
| `wontfix`                    | `wontfix`              | 対応しない                           |

skill がロール名に言及した場合(例:「AFK 対応可能を示す triage ラベルを付ける」)、この表の対応するラベル文字列を使う。

実際に使用する語彙に合わせて、右列を編集すること。
